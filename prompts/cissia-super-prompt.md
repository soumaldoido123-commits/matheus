# Cissia — Super prompt «DO NOT TOUCH»

Criado pela equipe de 13 agentes a partir dos ~25 prompts de `prompts/referencias/` (3 rodadas: análise, síntese, revisão).
Formato igual ao do acervo: chinês tradicional, falas em inglês, referência `@Video1`.
A análise completa está em `prompts/analise-da-equipe.md`.

---

## 1. Bíblia da Cissia (bloco fixo — cole no início de qualquer prompt)

```
【Cissia 角色鎖定】
以 @Video1 為唯一角色參考：臉、髮型、服裝、配色、身材比例完全照 @Video1。
- 頭上兩束金色雙馬尾、身後一條蛇尾，不多不少；蛇尾的顏色與粗細照 @Video1。
- 耳朵完全照 @Video1，不另外加任何獸耳。
- 一排鯊魚齒；瞳孔內十字高光。
- 3D 賽璐璐渲染：平塗 2–3 階色、硬邊灰紫陰影、墨線永遠清楚；皮膚霧面、沒有油光。
- 表情再誇張也是同一張臉：五官穩定、不變形、不融化。
聲線照 @Video1：年輕、慵懶時拖尾音、興奮時變尖；台詞短，常被吞嚥、咀嚼或呼吸打斷。

【Cissia 表演規則】
1. 眼睛先動，頭慢半拍跟上，身體最後。
2. 每個動作都有看得見的預備、動作、收勢，收勢帶一點過衝再回穩。
3. 尾巴比臉誠實：她嘴上說謊時，尾巴先洩漏真正的情緒。
4. 每次停下來，馬尾與蛇尾晚半拍才落定。
5. 重量真實：落地屈膝、腳踩實地，不漂浮、不滑步。
6. 定住時身體完全靜止一拍，馬尾與蛇尾仍在輕輕飄。
```

## 2. Super prompt — versão de 15s em um prompt só

```
（貼上【Cissia 角色鎖定】與【Cissia 表演規則】）

【片名】《DO NOT TOUCH》｜15 秒｜直式 9:16｜stylized 3D anime 喜劇。Cissia 是 3D 賽璐璐，世界是體素方塊風，兩種渲染互不混合。

【一句話】深夜在體素博物館值夜班的 Cissia，負責看守最後一顆焦糖布丁。她只用木叉碰了一下「做品質檢查」，整座展台就連鎖崩裂；她撲倒救下布丁，把罪推給一隻貓——然後發現監視器一直在拍。

【空間】單一場景：閉館後的體素博物館展廳。畫面左側是展台：邊緣缺一角的白瓷盤上放著最後一顆焦糖布丁，頭頂一盞小射燈只照亮布丁那一小圈；展台前一條深褐色絨繩，旁邊立著手寫紙牌「DO NOT TOUCH」。畫面右側是 Cissia。右後方高處的展櫃頂上趴著一隻方塊灰貓。展廳入口上方收著一道鐵捲門。天花板角落有一台監視器，亮著一顆小綠燈。她與展台的連線是 180 度軸，全片不越軸。所有道具第一幀就在畫面裡。

【造型】完全照 @Video1，外加夜班保全配件：一頂太大的保全帽（一鏡比一鏡更歪：眉毛上方→歪斜→壓住一邊眉毛，兩隻眼睛始終看得見）、一支手電筒、腰間的對講機，對講機旁邊別著一支木叉（她自己帶的）。

【光】光源只有三個：她的手電筒（暖白）、展台射燈（像冰箱燈的昏黃，只照布丁一小圈）、天窗透進來的石板藍月光。世界是低飽和的苔石灰綠。除了 Cissia 本身照 @Video1 的配色，全片不出現純紅；唯一一次純紅是崩裂時天花板的旋轉警報燈，只亮大約一秒。畫面乾淨，沒有後製光暈，只有燈泡本身有一點光暈。

【鏡頭一】0–6 秒｜24mm，貼著展台高度，緩慢推近、全程不停
0–1 秒：前景是布丁在瓷盤上自己輕輕晃（沒有人碰它），清楚對焦；後景虛焦是手電筒的光圈和她死盯著布丁的雙眼。焦點慢慢從布丁移到她的眼睛。
1–3.5 秒：她側身四分之三轉向展櫃上的貓，臉留在畫面內，一本正經地說：「Relax, buddy. I don't even like pudding.」說話的同時，她的蛇尾在身後像指南針一樣直直指向布丁，尾尖微微發抖。
3.5–6 秒：她說完，手不看就把蛇尾按回腿側；半秒後蛇尾自己彈回來，又指向布丁。她的眼睛先往左瞟、再往右瞟，頭慢半拍才跟上。保全帽滑成歪斜。她舔一下嘴唇，吞一口口水。

【鏡頭二】6–11 秒｜從她右肩後方過肩；觸碰之後鏡頭完全鎖死
6–9 秒：她的尾巴先跨過絨繩，身體才被尾巴拉過去半步。她的右手從腰間抽出木叉，叉尖越靠近布丁越慢、微微發抖，小聲替自己找理由：「Quality... control.」叉尖在焦糖表面輕輕點一下——「叩」，小到可笑。接著她和鏡頭都完全不動，所有聲音抽掉，只剩她鼻子一次短促的吸氣；只有布丁還在晃，而且越晃越大。
9–11 秒：展台底部「喀」地裂出一道細縫→「喀喀」分岔→網狀裂紋加速爬過展台和地板。射燈熄滅的同時，天花板警報燈轉了一圈，紅光掃過她的臉一次。她的瞳孔先縮小、眉毛飛起，嘴巴才張開，肩膀最後聳起。布丁從盤子上彈起來，她往前撲。

【鏡頭三】11–15 秒｜監視器視角：略高、正對、完全不動（硬切，崩塌已經發生）
11–12 秒：展台已經垮成一堆方塊碎塊，鐵捲門已經降下，把她關在展廳裡；警報燈已經停轉，只剩一點餘光。她趴在地上——撲倒時用瓷盤接住了布丁——左臂把瓷盤抱在胸口，右手握著木叉。布丁缺了一小口，齒痕朝向鏡頭；她嘴角沾著焦糖，一邊臉頰鼓起。保全帽歪到壓住一邊眉毛。
12–13 秒：她用木叉指向展櫃上的貓，嘴裡含著布丁、含糊地說：「He did it.」
13–14 秒：貓用爪子把地上的手電筒撥了一下，光圈正好照在她沾著焦糖的嘴角。她心虛地「咕嘟」吞下去，用手腕背面飛快擦掉嘴角的焦糖。
14–15 秒：她的瞳孔這才慢慢滑向鏡頭，瞳孔裡映出一個小綠點——監視器一直在拍——頭慢半拍才跟上，停留不到半秒；這是被抓包的反應，不是擺拍。畫面停住，環境音還在。不切黑。

【聲音】
環境音全程不斷：展櫃低沉的嗡鳴、遠處對講機斷斷續續聽不清的聲音、她尾巴掃過地板的沙沙聲，帶一點展廳回響。
配樂：一台便宜的塑膠電子小鍵盤彈一段五個音的輕快小旋律，最後一個音往上跳；加上舊弦烏克麗麗和低音撥弦。叉尖「叩」之後音樂完全消失，不再回來。結尾畫面停住時，小鍵盤單獨彈出那段旋律的最後一個音，低半音，自然延音到消失。
關鍵音效：開頭她「嗅、嗅」兩下；叉尖的「叩」；半拍絕對靜音；「喀→喀喀→喀喀喀」加速；鐵捲門落下；她心虛的「咕嘟」；最後展櫃壓縮機「喀」地停轉，房間只剩一點回響。
台詞出現時，音效降低。

【台詞】全片只有三句英文：「Relax, buddy. I don't even like pudding.」（一本正經）→「Quality... control.」（氣音，替自己找理由）→「He did it.」（嘴裡含著布丁，含糊）。最後被抓包的那一眼不說話。

【避免】
1. 不要角色漂移：頭上兩束馬尾、身後一條蛇尾，不多不少。
2. 除了結尾那不到半秒，不要看鏡頭。
3. 不要出現任何品牌、商標或既有的遊戲角色。
4. 結尾停在她被抓包的眼神上，畫面與環境音都繼續，不切黑、不閃白。
5. 鏡頭一緩慢推近，鏡頭二與鏡頭三完全穩定，不手持晃動。
```
