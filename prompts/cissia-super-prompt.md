# Cissia — Super prompt «DO NOT TOUCH»

Criado pela equipe de 13 agentes a partir dos ~25 prompts de `prompts/referencias/`.
Formato do prompt igual ao do acervo: chinês tradicional, falas em inglês, referência `@Video1`.

---

## 1. Bíblia da Cissia (bloco fixo — cole no início de qualquer prompt)

```
【Cissia 角色鎖定（全片只寫一次）】
以 @Video1 為唯一角色參考：臉、髮型、服裝、配色、身材比例完全照 @Video1。
- 金色雙馬尾兩束；耳朵完全照 @Video1，不另外加任何獸耳。
- 唯一一條蛇尾，顏色與粗細照 @Video1。畫面中的長條元素永遠只有三件：兩束馬尾＋一條蛇尾。
- 一排鯊魚齒；瞳孔內十字高光。
- 3D 賽璐璐渲染：平塗 2–3 階色、硬邊灰紫陰影、墨線永遠清楚；皮膚霧面、沒有油光。
- 表情再誇張也是同一張臉、同樣的眼睛、同樣的牙齒。
聲線照 @Video1：年輕、慵懶時拖尾音、興奮時變尖；台詞短，常被吞嚥、咀嚼或呼吸打斷。

【Cissia 表演規則】
1. 眼睛先動，頭慢半拍跟上，身體最後。
2. 每個動作都有看得見的預備、動作、收勢。
3. 尾巴比臉誠實：她嘴上說謊時，尾巴先洩漏真正的情緒。
4. 情緒分層切換：眼睛先變，嘴巴後跟，肩膀最後。
5. 每次停下來，馬尾與蛇尾晚半拍才落定，帶一點回彈。
6. 重量真實：落地屈膝、腳踩實地，不漂浮、不滑步。
7. 大反應用清楚的關鍵姿勢切換，節奏俐落，姿勢停得住。
8. 一個近景只換一次表情。
```

## 2. Super prompt — versão de 15s em um prompt só

```
（貼上【Cissia 角色鎖定】與【Cissia 表演規則】）

【片名】《DO NOT TOUCH》｜15 秒｜直式 9:16｜stylized 3D anime 喜劇。Cissia 是 3D 賽璐璐，世界是體素方塊風，兩種渲染互不混合。

【一句話】深夜在體素博物館值夜班的 Cissia，負責看守最後一顆焦糖布丁。她只用指尖碰了一下「做品質檢查」，整座展台就連鎖崩裂；她撲倒救下布丁，把罪推給一隻貓——然後發現監視器一直在拍。

【空間】單一場景：閉館後的體素博物館展廳。畫面左側是展台：邊緣缺一角的白瓷盤上放著最後一顆焦糖布丁，頭頂一盞小射燈只照亮布丁那一小圈；展台前一條深褐色絨繩，旁邊立著手寫紙牌「DO NOT TOUCH」。畫面右側是 Cissia。右後方高處的展櫃頂上趴著一隻方塊灰貓，全程幾乎不動。天花板角落有一台監視器，亮著一顆小綠燈。她與展台的連線是 180 度軸，全片不越軸。所有道具第一幀就在畫面裡。

【造型】完全照 @Video1，外加夜班保全配件：一頂太大的保全帽（每一鏡往下滑一點：眉毛上方→歪斜→遮住一隻眼）、一支手電筒、腰間的對講機，對講機旁邊別著一支木叉（她自己帶的）。

【光】光源只有三個：她的手電筒（暖白）、展台射燈（像冰箱燈的昏黃，只照布丁一小圈）、天窗透進來的石板藍月光。世界是低飽和的苔石灰綠。除了 Cissia 本身照 @Video1 的配色，全片不出現純紅；唯一一次純紅是崩裂時天花板的旋轉警報燈，只亮大約一秒。不要 bloom、不要鏡頭眩光、不要邊緣色差。

【鏡頭一】0–6 秒｜24mm，貼著展台高度，緩慢推近、全程不停
0–1 秒：前景是布丁在瓷盤上自己輕輕晃（沒有人碰它），清楚對焦；後景虛焦是手電筒的光圈和她死盯著布丁的雙眼。焦點慢慢從布丁移到她的眼睛。
1–3.5 秒：她轉身背對布丁，對著展櫃上的貓，一本正經地說：「Relax. Zero interest.」說話的同時，她的蛇尾在身後像指南針一樣直直指向布丁，尾尖微微發抖。
3.5–6 秒：她的眼睛先往左瞟、再往右瞟，頭慢半拍才跟上；她用手電筒照一下貓，貓只眨一下眼。保全帽滑成歪斜。她舔一下嘴唇，吞了一口口水。

【鏡頭二】6–11 秒｜從她右肩後方過肩；觸碰之後鏡頭完全鎖死
6–7.8 秒：她的尾巴先跨過絨繩，身體才被尾巴拉過去半步。她伸出一根手指，越靠近布丁越慢，指尖發抖，小聲替自己找理由：「Quality... control.」
7.8–8.4 秒：指尖在焦糖表面輕輕點一下——「叩」，小到可笑。
8.4–8.9 秒：半拍絕對靜止。鏡頭鎖死，所有聲音抽掉，只剩她鼻子一次短促的吸氣。布丁的晃動沒有停，反而越晃越大。
8.9–11 秒：展台底部「喀」地裂出一道細縫→「喀喀」分岔→網狀裂紋加速爬過展台和地板。射燈閃兩下後熄滅，那一圈暖光消失；天花板警報燈開始旋轉，紅光掃過她的臉一次。她的瞳孔先縮小、眉毛飛起，嘴巴才張開，肩膀最後聳起。布丁從盤子上彈起來。

【鏡頭三】11–15 秒｜監視器視角：略高、正對、完全不動（硬切，崩塌已經發生）
11–12.5 秒：展台已經垮成一堆方塊碎塊，鐵捲門已經降下，把她關在展廳裡。她趴在地上，雙手把瓷盤和完好的布丁緊緊抱在胸口，右手還握著木叉。保全帽遮住一隻眼；嘴角沾一點焦糖，一邊臉頰鼓起——她已經偷吃了一口。
12.5–13.5 秒：她用木叉指向展櫃上的貓，嘴裡含著布丁、含糊地說：「He did it.」貓慢慢眨一下眼，轉頭舔自己的爪子。
13.5–15 秒：她心虛地「咕嘟」吞下去。她的瞳孔慢慢滑向鏡頭——發現監視器的小綠燈一直亮著——頭慢半拍才跟上，停留不到半秒；這是被抓包的反應，不是擺拍。畫面停住：警報燈停轉，手電筒倒在地上照著一片灰塵，環境音回來。不切黑。

【聲音】
環境音全程不斷：展櫃低沉的嗡鳴、遠處對講機斷斷續續聽不清的聲音、她尾巴掃過地板的沙沙聲，帶一點展廳回響。
配樂：一台便宜的 Casio 小鍵盤彈五個音的主題（G G E~ A C!），加上舊弦烏克麗麗和低音撥弦，節奏輕快。指尖「叩」之後音樂完全消失，不再回來。結尾畫面停住時，小鍵盤單獨彈出主題的最後一個音，低半音，自然延音到消失。
關鍵音效：開頭她「嗅、嗅」兩下；指尖的「叩」；半拍絕對靜音；「喀→喀喀→喀喀喀」加速；鐵捲門落下；她心虛的「咕嘟」；最後警報燈停轉的「喀」一聲。
有台詞的時候，音效讓開。

【台詞】全片只有三句英文：「Relax. Zero interest.」（一本正經）→「Quality... control.」（氣音，替自己找理由）→「He did it.」（嘴裡含著布丁，含糊）。

【避免】
1. 不要角色漂移；長條元素永遠只有兩束馬尾＋一條蛇尾。
2. 除了結尾那不到半秒，不要看鏡頭。
3. 不要出現任何品牌、商標或既有的遊戲角色。
4. 不要切黑、不要閃白、不要停在最飽和的一幀。
5. 不要手持晃動：鏡頭一緩慢推近，鏡頭二與鏡頭三完全穩定。
```

Gere na ordem. Se a ferramenta aceitar imagem inicial, use o último frame da tomada anterior.

**Tomada A — 6s**
